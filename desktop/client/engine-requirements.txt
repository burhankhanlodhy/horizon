# Runtime dependencies of the ContextShrink Code engine (Windows x86_64, CPython 3.12).
#
# The closure of contextshrink[proxy] (pyproject.toml: the base dependencies plus
# [project.optional-dependencies] proxy), plus cryptography, which
# horizon/code_engine/license.py needs to verify the plan note. Every package is
# pinned to the version uv.lock resolves, so the engine runs the code the repo's
# CI tests. Installed by desktop/client/build-client-embed.ps1 -Engine (see
# build-engine-embed.ps1) with exactly these pins: --no-deps, --only-binary=:all:.
#
# Not included on purpose: embed-requirements.txt (the desktop client's set, which
# only runs the lightweight relay and has no proxy stack); keyring and the vault
# extra (the engine keeps nothing in the OS credential store); horizon itself
# (the build copies its source tree).
#
# Regenerate after changing pyproject.toml or uv.lock, from the repo root.
# uv export has no target-platform option, so the lock is exported first as the
# pin set; then uv pip compile resolves the proxy extra for win_amd64 / CPython
# 3.12 with those pins as constraints:
#   uv export --frozen --extra proxy --no-dev --no-hashes --no-annotate --no-header -o pins.txt
#   uv pip compile pyproject.toml --extra proxy --python-platform x86_64-pc-windows-msvc \
#     --python-version 3.12 --no-header --no-annotate -c pins.txt \
#     -o desktop/client/engine-requirements.txt
